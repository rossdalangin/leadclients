# Master Launch Checklist: The Business OS

## 🛠️ Step 1: Technical Foundation
- [ ] Install WordPress 6.0+
- [ ] Activate **GrowthPress Theme**
- [ ] Activate **GrowthPress Core Plugin**
- [ ] Set Permalinks to "Post Name"

## 🤖 Step 2: AI & API Integration
- [ ] Input **OpenAI API Key** (platform.openai.com)
- [ ] Input **Twilio SID & Token** (Optional for SMS)
- [ ] Input **Google Maps Key** (Optional for location routing)
- [ ] Set **Bearer API Token** (Security > Settings)

## 🚀 Step 3: Industry Initialization
- [ ] Run **OS Launch Wizard** from Dashboard
- [ ] Select Niche (e.g. Solar, Law)
- [ ] Verify core pages created (Home, Services, Contact, FAQ)
- [ ] Verify Custom Post Types created (Leads, Projects, Cases)

## 🎨 Step 4: Brand Calibration
- [ ] Set **Primary Brand Color** (Customizer > Global Branding)
- [ ] Upload **Logo** & **Favicon**
- [ ] Update **Hero Headline** & **Subheadline** (Customizer > Homepage)

## 📊 Step 5: Sales Operations
- [ ] Add team members as Users
- [ ] Set **Hot Lead Threshold** (Standard: 80)
- [ ] Verify **Kanban Stages** match niche workflow
- [ ] Submit test lead & verify AI scoring in Dashboard
