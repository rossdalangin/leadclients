# GrowthPress User Guide

Welcome to your AI Business Operating System.

## 🚀 Quick Launch
1. **API Setup**: Enter your OpenAI key in **Settings**.
2. **Niche Setup**: Use the **System Initializer** on the main dashboard to build your site structure instantly.
3. **Customize Branding**: Go to **Appearance > Customize** to set your primary brand colors.

## 🧠 AI Features
- **CRM Predictions**: Each lead card shows an "AI Confidence" percentage (probability of closing).
- **Triage**: Use the specialized calculators (Solar, Contractor) and Triage tools (Medical) on your frontend.
- **Content Studio**: Generate blogs, social posts, and ad copy tailored to your industry.

## 🛡️ Cybersecurity Best Practices
- Never share your OpenAI API Key.
- Use a secure "Bearer Token" for any Zapier/Make.com integrations.
- GrowthPress uses nonces for all form submissions to prevent unauthorized data entry.
